
# function

## paraments

参数形式|	是否拷贝|	函数内能否改外部对象|	典型用途
|-|-|-|-|
void f(int x)	|拷贝值	|不能改外部 int|	小类型、需要副本
void f(std::string s)|	拷贝/移动构造副本|	改 s 不改外部；但浅拷贝共享资源例外|	需要一份独立副本、sink 参数
void f(T& x)	|不拷贝	|能，通过 x 修改就是改外部	|输出参数、必须修改实参
void f(const T& x)|	不拷贝|	不能通过 x 修改|	只读大对象，避免拷贝
void f(T* p)	|拷贝指针	|改 *p 会改指向对象；改 p 不改外部指针|	可选参数、可能为空
void f(T&& x)	|不拷贝，绑定右值|	可修改右值对象；传 std::move(x) 后源对象可能被掏空|	移动构造、完美转发
